# 质量标准

## 必过检查

```bash
npm run verify
git diff --check
```

`verify` 包含：

1. `tests/*.test.ts` 的单元测试；
2. vinext 生产构建；
3. `tests/*.test.mjs` 的页面与治理契约测试；
4. ESLint。

## 变更类型与额外验证

| 改动 | 额外要求 |
| --- | --- |
| UI、交互、移动布局 | 浏览器目标流程、控制台、至少一个手机尺寸 |
| 推荐逻辑 | 覆盖临期、时间、口味、最近做过与排除场景的测试 |
| 认证、session、家庭隔离 | 失败测试、错误路径与旧摘要兼容性验证 |
| D1 模式、查询、mutation | 迁移审查、家庭范围测试、重复请求与离线重放测试 |
| 部署 | CI 通过、Webhook/Secret 影响审查、线上首屏健康检查 |

## 完成定义

一项工作完成当且仅当：验收条件满足、相关测试通过、任务与 Issue 状态更新、必要文档更新，并且没有未解释的控制台错误或数据安全风险。
